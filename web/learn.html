01 · PLANNING

상품 하나보다, 해결할 불편 하나를 고르세요

상품 이름만 적으면 소개할 기능이 늘어나기 쉽습니다. 먼저 ‘누가, 어떤 상황에서, 무엇 때문에 불편한가’를 한 문장으로 적어보세요. 그다음 영상에서 실제로 보여줄 수 있는 변화 하나를 고릅니다. 시청자의 상황이 구체적일수록 필요한 장면과 빼도 되는 설명이 분명해집니다.

기획 예시 · 케이블 홀더

넓은 주제: 편리한 책상용품 소개

좁힌 주제: 충전선을 책상 아래에서 매번 찾는 사람에게, 손이 닿는 자리에 선을 고정하는 방법 보여주기

촬영할 변화: 선이 아래로 떨어지는 장면 → 홀더에 고정하는 손 → 다시 집어 드는 장면

대본은 네 칸으로 시작하세요

  1. 도입: 시청자가 겪는 상황을 바로 보여줍니다. ‘이거 정말 좋아요’보다 ‘충전선이 또 책상 아래로 떨어졌나요?’처럼 장면과 연결되는 문장이 구체적입니다.
  2. 해결: 사용 과정을 보여줍니다. 기능을 열거하기보다 손동작과 결과가 보이도록 적습니다.
  3. 확인: 구매 전에 확인할 조건을 넣습니다. 예를 들어 케이블 두께, 책상 표면, 부착 방식처럼 시청자마다 달라질 수 있는 부분입니다.
  4. 마무리: 더 알아볼 경로와 제휴 관계를 명확히 안내합니다. 광고·제휴 표시 방식은 게시 플랫폼과 적용 규정을 별도로 확인해야 합니다.

저장은 일찍, 완성은 단계별로

쇼츠플로우에서는 주제만 입력해도 기획을 저장할 수 있습니다. 상품명·대본·제휴 링크는 내용을 확인한 뒤 추가하세요. 대본에 적은 장점이 실제 사용 경험이나 확인한 자료로 설명 가능한지 검토하고, 아직 확인하지 못한 내용은 확정된 사실처럼 쓰지 않습니다.

02 · PRODUCTION

제작 상태는 ‘진행률’보다 다음 할 일을 알려줘야 해요

아이디어가 많아도 다음 작업이 불분명하면 게시로 이어지기 어렵습니다. 쇼츠플로우의 다섯 상태는 아래처럼 통과 조건을 정해 사용해보세요. 모든 기획에 같은 양의 시간을 쓰기보다, 막힌 단계를 확인하는 데 목적이 있습니다.

  1. 아이디어: 보여줄 불편과 변화가 한 문장으로 정리됐는지 확인합니다.
  2. 대본 검토: 장면별 설명이 실제 촬영 가능한지, 확인되지 않은 표현이나 과장된 약속이 없는지 살핍니다.
  3. 편집: 필요한 화면·자막·음성을 준비합니다. 사용 권한이 있는 자료인지 확인하고, 작은 화면에서도 핵심 자막을 읽을 수 있는지 봅니다.
  4. 게시 승인: 링크, 제휴 안내, 자막 오탈자, 게시일을 마지막으로 확인합니다. 혼자 작업한다면 스스로 하는 최종 점검 단계로 사용해도 됩니다.
  5. 게시 완료: 플랫폼에 실제 게시한 뒤 영상 URL을 남깁니다. 쇼츠플로우에서 상태를 바꾸는 것만으로 외부 플랫폼에 영상이 올라가지는 않습니다.

일정이 바뀌면 날짜와 상태를 함께 점검하세요

게시 예정일은 ‘희망 날짜’보다 다음 행동을 정하는 기준으로 쓰세요. 촬영이 늦어졌다면 날짜만 미루지 말고, 어떤 장면이나 확인 사항 때문에 멈췄는지 대본에 한 줄 남깁니다. 다음에 열었을 때 다시 판단할 시간을 줄일 수 있습니다.

게시 전 짧은 점검

□ 소개한 조건과 실제 상품 정보가 맞는가
□ 영상과 자막에서 전달하는 내용이 일치하는가
□ 링크가 열리고 목적지와 일치하는가
□ 제휴·광고 관계를 필요한 방식으로 안내했는가
□ 실제 게시 후 URL과 상태를 기록했는가

일정 화면은 저장한 게시일을 기준으로 보여줍니다. 자동 게시와 플랫폼 계정 연동은 현재 제공하지 않으므로, 외부 플랫폼의 예약 게시 여부는 해당 플랫폼에서 확인하세요.

03 · MEASUREMENT

클릭 수와 확정 수수료를 같은 기간으로 기록하세요

하루치 클릭 수와 한 달치 수수료를 비교하면 어떤 기획이 효과적이었는지 판단하기 어렵습니다. 먼저 기록할 기간을 정하고, 같은 출처와 같은 집계 기간의 값을 비교하세요. 조회·클릭·주문·수수료는 서로 다른 지표이므로 하나를 다른 지표로 해석하지 않는 것이 좋습니다.

아직 확정되지 않은 수익은 구분하세요

제휴 플랫폼에는 추정 수익과 확정 수익이 나뉘어 표시될 수 있습니다. 쇼츠플로우의 ‘확정 수수료’에는 해당 플랫폼에서 확정된 금액을 입력하세요. 취소나 반품으로 금액이 바뀌었다면 확인한 값으로 수정하고, 확인 시점을 대본 메모에 남기면 이후 대조에 도움이 됩니다.

기록 예시 · 비교 기준 맞추기

A 영상과 B 영상을 비교할 때 두 영상 모두 게시 후 같은 기간의 클릭 수를 기록합니다. 예를 들어 ‘게시 후 7일’로 정했다면, B 영상이 하루밖에 지나지 않은 상태에서 A 영상의 7일 수치와 우열을 결정하지 않습니다.

이 예시는 기록 방법에 대한 설명이며, 특정 클릭 수나 수익을 보장하지 않습니다.

숫자 하나에서 원인을 단정하지 마세요

클릭 수가 늘었다면 주제 외에도 노출량, 게시 시각, 링크 위치가 달랐는지 확인합니다. 다음 기획에서는 가능한 한 바꾸려는 요소 하나를 정하세요. 도입 문장을 바꾸거나 구매 전 확인 사항을 더 구체적으로 보여주는 식으로, 무엇을 비교하는지 적어두는 것이 좋습니다.

백업과 개인정보 점검

CSV 내보내기는 직접 기록한 작업을 별도로 보관할 때 사용할 수 있습니다. 내보낸 파일에는 대본과 링크 등이 포함되므로 공유 전에 내용을 확인하세요. 쇼츠플로우의 클릭 수와 수익 리포트는 직접 입력한 값을 보여주며 외부 플랫폼에서 자동으로 수집하거나 검증하지 않습니다.
